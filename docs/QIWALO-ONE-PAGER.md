# قيوالو — One-Pager للمستثمرين

**سطر واحد:** سوق إقامة عربي (RTL) للأقصر وأسوان يربط المسافرين العرب بملاك الوحدات والفنادق الصغيرة، بعمولة **12%** على الحجز المؤكد فقط.

**التاريخ:** نوفمبر 2026 · **المرحلة:** MVP منشور ومشغول · **الموقع:** `https://qiwalo-ygzh.vercel.app/`

---

## 1. المشكلة
- العروض في الأقصر وأسوان متشتتة بين منصات أجنبية ومجموعات واتساب ومكالمات مباشرة.
- المسافر العربي لا يجد تجربة عربية واضحة وسعراً نهائياً بدون مفاجآت.
- المالك الصغير بيدفع عمولات عالية أو يفتقر لقناة بيع موثوقة.
- غياب التوثيق والمراجعات الحقيقية يضعف الثقة قبل الدفع.

## 2. الحل
منصة ويب متجاوبة بالكامل بالعربية وRTL:
- بحث بفلاتر (المدينة، النوع، السعر، التقييم، المرافق) وترتيب.
- صفحة وحدة فيها صور، مواصفات، قواعد، خريطتين (الوحدة + الاستلام) واتجاهات Google Maps.
- حجز فوري ببيانات الضيف والجنسية وطريقة الدفع، مع تأكيد ورقم مرجعي.
- **توثيق المالك** بالبطاقة + سيلفي بعد الموافقة المبدئية، ومراجعة إدارية قبل النشر.
- تقييمات الضيوف بعد إتمام الإقامة، تروح للإدارة للمراجعة قبل الظهور.
- دعم فوري: Tawk.to + واتساب/تليجرام **01066094050**.

## 3. نموذج الإيرادات
| البند | التفاصيل |
|---|---|
| العمولة | **12%** تُقتطع من المالك بعد تأكيد الحجز فقط |
| المرونة | نسبة قابلة للتعديل لكل مالك/شريك (للتسويق الخارجي) |
| الاشتراكات | لا يوجد اشتراك أو رسوم نشر حالياً |
| الدفع الآن | تحويل بنكي أو كاش عند الوصول — بدون دفع إلكتروني |
| الجاهزية | Paymob webhook مطبّق ومختبر؛ الـ checkout الحي على خارطة الطريق |

## 4. أين نحن الآن (Traction)
- ✅ المنصة منشورة على Vercel وتقرأ من Supabase Postgres الحقيقي.
- ✅ Supabase Auth (إيميل + باسورد) بأدوار GUEST / OWNER / ADMIN.
- ✅ Cloudinary لتخزين صور الوحدات برفع موقّع من السيرفر.
- ✅ **40 وحدة عرض + 10 ملاك + 94 تقييم** بيانات تجريبية منظمة.
- ✅ مسار كامل مختبر: مالك يضيف وحدة → إدارة تنشرها → ضيف يحجز → إشعار موثق في الـ logs.
- ✅ شات Tawk.to شغال في كل الصفحات.

## 5. السوق والفرصة
- الأقصر وأسوان وجهتان سياحيتان دائمتان بطلب عربي متزايد وتجربة عربية ناقصة.
- النموذج «خفيف الأصول»: لا نملك عقارات، لا مخزون، وتكلفة التشغيل منخفضة (Supabase + Vercel + Cloudinary).
- قابلية التوسع: نفس نموذج الـ repo/API يسمح بتطبيق Flutter لاحقاً بدون إعادة بناء الـ backend.
