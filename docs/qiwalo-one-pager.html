سوق إقامة عربي (RTL) للأقصر وأسوان يربط المسافرين العرب بملاك الوحدات والفنادق الصغيرة، بعمولة 12% على الحجز المؤكد فقط.

١. المشكلة

  • العروض متشتتة بين منصات أجنبية وواتساب ومكالمات مباشرة.
  • المسافر العربي مفيش تجربة عربية واضحة وسعر نهائي بدون مفاجآت.
  • المالك الصغير بيدفع عمولات عالية أو يفتقر لقناة بيع موثوقة.
  • غياب التوثيق والمراجعات الحقيقية يضعف الثقة قبل الدفع.

٢. الحل

  • بحث بفلاتر وترتيب + صفحة وحدة بالصور والمواصفات والقواعد.
  • خريطتان (الوحدة + الاستلام) وزر اتجاهات Google Maps.
  • حجز فوري برقم مرجعي + تأكيد، وتقييمات بعد إتمام الإقامة.
  • توثيق المالك بالبطاقة والسيلفي ومراجعة إدارية قبل النشر.
  • دعم: Tawk.to + واتساب/تليجرام 01066094050.

  • مسار كامل مختبر: مالك يضيف وحدة → إدارة تنشرها → ضيف يحجز → إشعار موثّق في الـ logs.
  • بيانات عرض منظمة: 40 وحدة، 10 ملاك، 94 تقييم.

٥. السوق والفرصة

  • الأقصر وأسوان وجهتان دائمتان بطلب عربي متزايد وتجربة عربية ناقصة.
  • نموذج خفيف الأصول: لا عقارات ولا مخزون وتكلفة تشغيل منخفضة.
  • نفس الـ API يسمح بتطبيق Flutter لاحقاً بدون إعادة بناء الـ backend.

٦. خطة ٦ أشهر

  • اعتماد الصياغة النهائية للشروط + دومين مخصص.
  • تفعيل Paymob checkout الحي.
